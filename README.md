Portfolio de Chakib

Portfolio personnel présentant mon profil d'étudiant en ingénierie mécanique (spécialité énergétique), passionné d'informatique, de mécanique et de développement web.

 Aperçu

Ce site présente en une seule page mon parcours, mes compétences et mes projets :

- **À propos de moi** — formation, intérêts, langues, certifications
- **Compétences** — logiciels, technologies, compétences académiques et personnelles
- **Formation & expérience** — parcours académique, formations, certifications, expériences professionnelles
- **Projets** — mise en avant de mes réalisations : site sur les lanceurs spatiaux, application de gestion de stock, sites Pradice Nettoyage et Thilelli, MenuiCAD, design de logos et branding
- **Contact** — formulaire et informations de contact

 Technologies utilisées

- HTML5 / CSS3 / JavaScript (vanilla)
- [Lucide Icons](https://lucide.dev/) pour les icônes
- Site conçu comme une application single-page, sans dépendances lourdes
